## [1.0.0]

### Added
- Initial multi-loader release of Item Display Control for Fabric and NeoForge.
- Per-target placement protection for item frames, pots, lecterns, jukeboxes, campfires, composters, respawn anchors, and armor stands.
- Configurable whitelist and blacklist item filters managed via in-game settings GUI.
- Sneak-to-bypass and adjacent block placement bypass functionality.
- Full client-side operation with zero server dependencies.
