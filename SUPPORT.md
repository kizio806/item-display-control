# Support Guidelines — Item Display Control

Thank you for using **Item Display Control**. Here is how to find documentation, report issues, and request assistance.

---

## 1. Documentation Resources

Please check the project documentation before opening an issue:
- [Installation Guide](docs/installation.md): Mod loader setup for Fabric and NeoForge.
- [User Guide](docs/wiki/User-Guide.md): Configuration options, target toggles, and item whitelists.
- [Troubleshooting](docs/troubleshooting.md): Answers to common questions and conflict diagnosis.
- [Architecture](docs/architecture.md): Overview of interaction guards and mathematical projection.

---

## 2. Issue Tracking

Use [GitHub Issues](https://github.com/kizio806/item-display-control/issues) for:
- **Bug Reports**: Unexpected item insertions or bypass calculation failures.
- **Feature Requests**: Suggestions for additional decoration block support or GUI improvements.
- **Compatibility Notes**: Reports regarding conflicts with other client or rendering mods.

Please select the matching issue template when creating a report.

---

## 3. Security Inquiries

To report security concerns or client crash risks, please refer to our [Security Policy](SECURITY.md) to report privately.
