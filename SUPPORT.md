# Support Policy

Thank you for using **Item Display Control**. This document provides guidelines on how to get assistance, report bugs, ask compatibility questions, and engage with the maintainers.

---

## 📖 Getting Help

Before opening an issue, please consult the documentation:
- [Installation Guide](docs/installation.md) — Loader installation (Fabric & NeoForge), dependencies, and version matrix.
- [Troubleshooting](docs/troubleshooting.md) — Conflict resolution, target protection diagnostics, and keybindings.
- [Architecture Guide](docs/architecture.md) — Module separation, client interaction guards, and state flow.
- [Wiki Documentation](docs/wiki/Home.md) — Comprehensive user guides, compatibility charts, and development practices.

---

## 💬 Communication Channels

### 1. GitHub Issues
GitHub Issues are reserved for:
- **Bug Reports:** In-game interaction anomalies, unintended item placements, or bypass vector miscalculations.
- **Feature Requests:** Configuration options, new container target suggestions, GUI refinements, or keybinding improvements.
- **Compatibility Reports:** Verifications or issues observed with specific client or rendering mods.

Please use the appropriate [Issue Template](.github/ISSUE_TEMPLATE) when submitting tickets.

### 2. Security Vulnerabilities
If you identify a security or client-safety issue, please review our [Security Policy](SECURITY.md) and submit a report privately via [GitHub Security Advisories](https://github.com/kizio806/item-display-control/security) rather than using public issues.

### 3. Community Discussions
For gameplay discussions, modpack recommendations, or general help, visit our [GitHub Discussions](https://github.com/kizio806/item-display-control/discussions).
