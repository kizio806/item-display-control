# GitHub Wiki Source

This directory contains the source markdown files for the official [Item Display Control GitHub Wiki](https://github.com/kizio806/item-display-control/wiki).

All files here are automatically mirrored to the GitHub Wiki repository on every push to `main` via the [`.github/workflows/wiki-sync.yml`](https://github.com/kizio806/item-display-control/blob/main/.github/workflows/wiki-sync.yml) workflow.
